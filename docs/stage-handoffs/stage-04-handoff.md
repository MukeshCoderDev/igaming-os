## 2. Contracts Phase 5 must honor

Phase 5 inherits the following contracts from Phase 4. Violations
are linter failures.

### 2.1 Lint contract

- **Rules 1–23** re-run on every PR; CI green.
- New ADRs and DECs added in Phase 5 must satisfy rules 6, 7, 10, 11.
- New ADRs must use Nygard format (rule 10).

### 2.2 Test contract

- **mypy strict list** grows per phase. Phase 5 must add new modules
  to `[[tool.mypy.overrides]]` in `pyproject.toml`.
- **Coverage diff ≥80%** on every PR (rule enforced by CI via
  `diff-cover`).
- **Coverage baseline** (`.coverage-baseline-phase4.txt`) is locked;
  Phase 5 baseline target: 80%@10 (per ADR-0027).
- **Branch coverage** is optional in Phase 5; mandatory from Phase 8.

### 2.3 Error contract

- All new API endpoints must use `problem_response()` from
  `src/noventra/errors/handlers.py` for error responses.
- New error codes must be added to
  `src/noventra/errors/catalog.py` (one HTTP status per code).
- `docs/architecture/error-catalog.md` must be regenerated when
  codes are added.
- Stack traces must NEVER appear in production responses (DEBUG=False
  → no `traces` field).

### 2.4 Logging contract

- All new modules must use `get_logger()` from
  `src/noventra/observability/logging.py`.
- The RedactingProcessor runs at the logger boundary; new PII fields
  must be added to `PII_FIELD_NAMES` in `redaction.py`.
- 1-in-100 sampling on /health/ and /metrics/ is enforced by
  `should_sample()`.
- `correlation_id` is bound to structlog contextvars by
  `CorrelationIdMiddleware`; downstream log lines automatically
  carry it.

### 2.5 Citation contract

- Every NFR, STRIDE finding, and PII class cited in Phase 5 work
  must appear in the trace matrices (`docs/architecture/traces.md`).
- New artifacts must be added to the appropriate trace matrix
  section.
- Linter rule 20 verifies trace matrix coverage.
