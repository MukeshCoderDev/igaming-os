# ADR-0094 — Game Session WebSocket Consumer

## Context

Game sessions require real-time bidirectional communication (bet stream, outcome push). Phase 14 pulled forward minimal ASGI + WebSocket infrastructure for kill switch. Phase 15 extends this for game sessions.

## Decision

GameSessionConsumer (WebSocket consumer): player session; bet stream; outcome push; disconnect on kill switch. Builds on Phase 14 KillSwitchConsumer infrastructure. Uses Django channels + Redis pub/sub.

## Alternatives

HTTP polling (rejected — latency); SSE (rejected — unidirectional).

## Consequences

ASGI + channels + Redis required (already in place from Phase 14). Connection registry for kill switch fan-out.

## Validation Plan

WebSocket connection test; bet stream test; outcome push test; kill switch disconnect test.
