# ADR-0051 — Retention model + jurisdiction-aware schedule + DSAR + right-to-erasure

## Context

GDPR Art. 5(1)(e) requires storage limitation. GDPR Art. 15 gives data subjects the right to access (DSAR). GDPR Art. 17 gives the right to erasure. The retention model must: define a default schedule per data class, allow jurisdiction overrides, enforce retention via a scheduled job, support legal hold, and handle archival to cold storage (Q5-blocked).

## Decision

Adopt a retention model with: (1) default schedule per data class (player profile: 7y after closure; consent records: 7y after revocation; login history: 2y; audit log: per Phase 7 ADR-0036); (2) jurisdiction overrides per (data_class, jurisdiction) tuple (Q1-blocked; Phase 9 uses defaults); (3) right-to-erasure flow (request → verify → erase → audit → respond; cascade to related data); (4) DSAR flow (request → verify → gather → format → deliver within 30 days; response-time tracking); (5) retention enforcement job (scheduled, audited); (6) legal hold mechanism (suspends retention for affected records); (7) archival to cold storage (Q5-blocked, ASSUMED-scaffolding). HUMAN-APPROVED per linter rule 5 (Legal/Regulatory category).

## Alternatives

Alternatives: (a) no retention model (keep forever) — GDPR violation; (b) global retention (no jurisdiction overrides) — non-compliant in stricter jurisdictions; (c) manual retention (no job) — error-prone. (a) rejected for GDPR; (b) rejected for jurisdiction variance; (c) rejected for errors.

## Consequences

Retention schedule is complex (many data classes × many jurisdictions). Right-to-erasure cascade must carefully handle: player profile, consents, login history, audit log (audit log is NOT erased — it's retained per Phase 7; the player's identity in audit is redacted instead). DSAR delivery infrastructure (file format, secure transfer) is Q5-blocked. Archival vendor is Q5-blocked.

## Validation Plan

Phase 9: retention model + schedule. Phase 9: erase_player + export_player_data + enforce_retention commands. Phase 9: right-to-erasure + DSAR flow tests. Phase 10: jurisdiction overrides (Q1). Phase 10: archival vendor (Q5).
