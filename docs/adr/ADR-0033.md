# ADR-0033 — Tenant resolution order (JWT claim + X-Tenant-ID + membership validation + switch)

## Context

Phase 5 introduced tenant resolution (ADR-0029) with JWT claim primary + X-Tenant-ID header fallback. Phase 6 adds user-tenant membership validation: the resolved tenant must be one the user is a member of (active membership). Multi-tenant users can switch tenants via a tenant-switch endpoint that re-issues a JWT with the new tenant claim. The resolution order must be explicit and documented.

## Decision

Adopt Option B (JWT claim primary + membership validation + X-Tenant-ID fallback for service accounts). Resolution order: (1) JWT `tenant_id` claim — validated against tenant_memberships (active) for human users; (2) X-Tenant-ID header — for service accounts (typ=service JWT) only; (3) missing/malformed → 400 E_TENANT_MISSING / E_TENANT_INVALID (Phase 5); (4) membership not found/inactive → 403 E_TENANT_FORBIDDEN. Tenant-switch endpoint: POST /auth/switch-tenant/ with tenant_id body; re-issues access + refresh JWT with new tenant claim. First-login default tenant: the user's first active membership (or explicitly set default_tenant on the user).

## Alternatives

Alternatives: (a) Option A (header-only) — spoofable; (b) Option C (URL path) — couples tenancy to routing; (c) Option D (DB lookup per request) — DB overhead. (a) rejected for spoofing; (b) rejected for coupling; (c) rejected for overhead. Option B chosen for security + flexibility.

## Consequences

JWT claim must be populated by the login flow. Membership validation adds one DB/cache lookup per request (mitigated by Redis cache). Tenant-switch invalidates the old JWT's tenant context (old refresh token blacklisted). Multi-tenant users with many memberships need a membership list endpoint (Phase 7).

## Validation Plan

Phase 6: tenant resolution extends Phase 5 middleware with membership validation. Phase 6: tenant-switch endpoint test. Phase 6: multi-tenant user first-login default tenant test. Phase 6: membership-inactive → 403 test. Phase 7: membership list endpoint + cache.
