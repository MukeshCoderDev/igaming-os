# ADR-0092 — Game Round Model + FSM + Bet→Ledger Posting

## Context

Game rounds require explicit FSM, bet acceptance, outcome settlement, and ledger posting continuity with Phase 11. Bets consume player balance; settlements post winnings to ledger.

## Decision

GameRound FSM: OPEN → CLOSED → SETTLED (or VOIDED/CANCELLED). Bets accepted during OPEN only. Settlement posts to Phase 11 ledger (debit house, credit player for winnings). Voiding returns bets via RealRoundVoidingAdapter. Uses Phase 8 state machine base. Every transition audited + outbox event.

## Alternatives

No FSM (rejected — no state control); mutable rounds (rejected — audit risk).

## Consequences

Two ledger accounts per player (real + bonus). Bet→ledger posting in same transaction as bet acceptance.

## Validation Plan

FSM transition tests; bet→ledger posting test; settlement test; void→reversal test.
