# ADR-0155 — Go/No-Go Decision & Launch Authorization

## Context

Phase 25 is the final gate. The Go/No-Go decision is the most consequential decision in the entire programme. If GO: Noventra launches. If NO-GO: Noventra does not launch until blockers resolved. This decision requires ALL named human approvers — no auto-approval; no unsigned gates.

The 2023 FTX collapse ($8B missing) is the canonical example of launching without governance: FTX launched without independent oversight; no external auditor; no compliance officer; no Go/No-Go gate; the founder made unilateral decisions; $8B in customer funds disappeared. The lesson: launch authorization requires multiple named human sign-offs — no single person can authorize launch; no unsigned gates.

Phase 25's Go/No-Go decision is the architectural mitigation: 20 release gates must all be GREEN; 16 named human approvers must all sign; the Go/No-Go document (`docs/launch/go-no-go.md`) records every gate status + every signature. If any gate is RED or any human unsigned → NO-GO. Noventra does not launch.

## Decision

### Go/No-Go decision framework

**GO conditions (ALL must be true):**
1. All 20 release gates GREEN (ADR-0154).
2. All validation suites pass (security + concurrency + chaos + load — ADR-0152).
3. Restore drill passed (ADR-0153).
4. Vulnerability scan clean (ADR-0153).
5. SLOs verified (ADR-0154).
6. All ADRs ACCEPTED with named human signatures (149+ ADRs).
7. All named humans signed (16 roles).
8. Q1/Q5 resolved or documented deferral (DEC-0064).
9. Financial invariants hold under concurrency.
10. Isolation holds under load.
11. Tipping-off prohibition verified (non-vacuous).
12. AI Boundary verified.
13. Conformance gate active (ADR-0020).
14. Increment 1-5 close reports signed.

**NO-GO conditions (ANY triggers NO-GO):**
- Any release gate RED or unsigned.
- Any validation suite fails.
- Restore drill fails.
- Vuln scan has HIGH/CRITICAL open (not allowlisted).
- Any ADR PROPOSED (unsigned).
- Any named human not signed.
- Q1/Q5 blocking (not documented deferral).
- Financial invariant fails under concurrency.
- Isolation fails under load.
- Tipping-off grep finds violations (criminal liability).
- AI Boundary violated (AI writes domain truth).
- Conformance gate not active.

## Alternatives

- **Auto-GO** (rejected). Human accountability required; regulator-mandated. The FTX collapse is the canonical example.
- **Partial GO (launch with known blockers)** (rejected). Regulator risk; player safety risk; criminal liability risk.
- **Single approver** (rejected). Multiple stakeholder perspectives required; no single person can authorize launch.
- **No Go/No-Go document** (rejected). Cannot prove governance; regulator inquiry cannot be answered.
- **Unsigned gates (trust-based)** (rejected). No accountability; FTX pattern.

## Consequences

- Go/No-Go decision (ALL 20 gates GREEN + ALL 16 humans signed → GO).
- Go/No-Go document produced (`docs/launch/go-no-go.md`).
- No launch without GO.
- No auto-approval; no unsigned gates.
- This is the final gate of the programme.
- Open question OQ-LAUNCH-004: MLRO appointment (OPEN).
