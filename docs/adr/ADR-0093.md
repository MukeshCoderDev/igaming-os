# ADR-0093 — Real RoundVoidingAdapter

## Context

Phase 14 created a StubRoundVoidingAdapter (logs only). Phase 15 implements the real adapter that actually reverses ledger entries and returns bets to players.

## Decision

RealRoundVoidingAdapter: void_round() reverses all bet ledger entries via Phase 11 reversal (terminal, references original). Called by: kill switch trigger, SE activation, reality check failure. Same DB transaction as round state transition.

## Alternatives

Async voiding (rejected — kill switch <200ms SLO requires synchronous).

## Consequences

Voiding is synchronous. Ledger reversal in same transaction as round void.

## Validation Plan

Void→reversal test; kill switch void test; SE void test; concurrent void test.

## Decision statement (one line)

DEC-0094 → Real RoundVoidingAdapter. Owner: Architecture Lead. Status: PROPOSED.
