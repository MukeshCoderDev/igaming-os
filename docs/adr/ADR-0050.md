# ADR-0050 — Player lifecycle FSM — states, transitions, regulatory constraints

## Context

Players have a regulated lifecycle: prospect → registered → active → suspended → self_excluded → dormant → closed → deleted. Some transitions have regulatory constraints: self-exclusion has a cooling-off period (jurisdiction-dependent, Q1-blocked); dormancy is defined by inactivity (jurisdiction-dependent). Every transition must be audited (Phase 7) and emit outbox events (Phase 8).

## Decision

Adopt an 8-state FSM using the Phase 8 state machine base (ADR-0044). States: prospect, registered, active, suspended, self_excluded, dormant, closed, deleted. Transitions: register (prospect→registered), activate (registered→active), suspend (active→suspended), reactivate (suspended→active), self_exclude (active→self_excluded), dormancy_trigger (active→dormant), close (any→closed), delete (closed→deleted). Regulatory constraints: self_exclude has a cooling-off period (Q1-blocked; Phase 9 uses 24h default); dormancy_trigger requires inactivity > N days (Q1-blocked; Phase 9 uses 365d default). Every transition: audited (Phase 7) + outbox event (Phase 8). HUMAN-APPROVED per linter rule 5 (Legal/Regulatory category).

## Alternatives

Alternatives: (a) free-form status field (no FSM) — invalid transitions; (b) fewer states (no self_excluded/dormant) — regulatory gap; (c) separate FSM per jurisdiction — complexity. (a) rejected for invalid transitions; (b) rejected for regulatory gap; (c) rejected for complexity.

## Consequences

8 states + 8 transitions = complex FSM. Regulatory constraints (cooling-off, dormancy) are Q1-blocked; Phase 9 uses defaults. Self-exclusion is a serious regulatory action (must not be reversible during cooling-off). Dormancy may trigger data retention enforcement (ADR-0051).

## Validation Plan

Phase 9: FSM implemented (Phase 8 base). Phase 9: every transition audited + outbox event. Phase 9: regulatory constraint tests (self-exclusion cooling-off, dormancy). Phase 10: jurisdiction-specific constraints (Q1 unblock).
